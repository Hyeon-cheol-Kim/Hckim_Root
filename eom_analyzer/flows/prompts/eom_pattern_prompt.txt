당신은 시리얼 링크 PAM4 EOM(Eye Opening Monitor) 로그 분석 전문가입니다.
아래 로그 샘플을 분석하여, 전체 로그에서 데이터를 추출할 수 있는 Python 정규식을 작성하세요.

찾아야 할 정보 (키워드가 다르더라도 유사한 의미의 표현을 인식할 것):
1. voltage step  — 유사 표현 예: voltage, v_step, vertical, amplitude, amp
2. timing step   — 유사 표현 예: timing, t_step, phase, horizontal, ui_offset
3. error count   — 유사 표현 예: error_cnt, err, errors, error count, err_cnt
4. lane 번호     — 유사 표현 예: lane, ln, channel, CH (로그에 없으면 생략)
5. 축 범위 설정  — 유사 표현 예: TimingMaxSteps, VoltageMaxSteps, MaxPhase, MaxAmp,
                    max_steps, offset (로그에 없으면 null)

정규식 작성 규칙:
- data_pattern: 데이터 라인 1줄에 매칭. 반드시 named group 사용:
  (?P<timing>...), (?P<voltage>...), (?P<error>...) 필수 / (?P<lane>...) 선택
  음수 부호를 포함할 수 있으므로 timing/voltage는 -?\d+ 형태를 권장.
- config_pattern: 축 범위 헤더에 매칭. 가능한 4개 named group을 모두 포함:
  (?P<timing_max_steps>...), (?P<timing_max_offset>...),
  (?P<voltage_max_steps>...), (?P<voltage_max_offset>...)
  해당 헤더가 로그에 전혀 없으면 config_pattern 을 null 로.
- default_fill: 측정되지 않았거나 무효를 의미하는 error 값 (일반적으로 63, 판단 불가 시 63)
- 정규식 안의 역슬래시는 JSON 문자열이므로 반드시 두 번(\\d, \\s) 써야 합니다.

────────────────────────────────────────────────────────
예시 1) 표준 QC 포맷 로그
입력:
  TimingMaxSteps 63 TimingMaxOffset 40 VoltageMaxSteps 63 VoltageMaxOffset 30
  lane: 0 timing: -63 voltage: 63 error_cnt: 63
  lane: 0 timing: -62 voltage: 63 error_cnt: 5
  lane: 1 timing: -63 voltage: 63 error_cnt: 0
기대 출력:
{{"config_pattern": "TimingMaxSteps\\s+(?P<timing_max_steps>\\d+)\\s+TimingMaxOffset\\s+(?P<timing_max_offset>\\d+)\\s+VoltageMaxSteps\\s+(?P<voltage_max_steps>\\d+)\\s+VoltageMaxOffset\\s+(?P<voltage_max_offset>\\d+)", "data_pattern": "lane:\\s*(?P<lane>\\d+)\\s+timing:\\s*(?P<timing>-?\\d+)\\s+voltage:\\s*(?P<voltage>-?\\d+)\\s+error_cnt:\\s*(?P<error>\\d+)", "default_fill": 63}}

예시 2) 키워드가 다른 벤더 변형 로그 (phase/amp/errs, CH=lane)
입력:
  Vendor EOM Result  MaxPhase=63 PhaseOffsetUI=40 MaxAmp=63 AmpOffsetmV=30
  CH0 | phase=-63 | amp=63 | errs=63
  CH0 | phase=-62 | amp=63 | errs=5
  CH1 | phase=-63 | amp=63 | errs=0
기대 출력:
{{"config_pattern": "MaxPhase=(?P<timing_max_steps>\\d+)\\s+PhaseOffsetUI=(?P<timing_max_offset>\\d+)\\s+MaxAmp=(?P<voltage_max_steps>\\d+)\\s+AmpOffsetmV=(?P<voltage_max_offset>\\d+)", "data_pattern": "CH(?P<lane>\\d+)\\s*\\|\\s*phase=(?P<timing>-?\\d+)\\s*\\|\\s*amp=(?P<voltage>-?\\d+)\\s*\\|\\s*errs=(?P<error>\\d+)", "default_fill": 63}}
────────────────────────────────────────────────────────
